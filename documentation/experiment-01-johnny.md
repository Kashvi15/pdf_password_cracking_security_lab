# Experiment 01: PDF Password Recovery Using Johnny

## Objective
To understand and perform PDF password recovery using Johnny, the graphical interface for John the Ripper.

## Tool Used
- Johnny (John the Ripper GUI)

## Procedure

1. Extracted the password hash from the instructor-provided sample PDF.
2. Saved the extracted hash in a text file.
3. Opened Johnny and loaded the hash file.
4. Started the password-recovery attack.
5. Observed the successful password recovery.

## Result

The PDF password was successfully recovered.

## Learning Outcomes

- Learned how PDF password hashes are used in password recovery.
- Gained practical experience with Johnny.
- Understood the basic workflow of hash-based password cracking.
